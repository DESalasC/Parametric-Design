Lección: Fix encoding JSON en GH/IronPython 2.7 para caracteres especiales
Problema
El script F1_ETAPA1_CONTEXTO_v02.py fallaba al leer archivos JSON que contenían caracteres especiales en español (como la 'ñ' en "DiseñoParametrico" o tildes) con el error:

ETAPA1 | ERROR al leer JSON: 'unknown' codec can't decode byte 0xf3 in position 8: Unable to translate bytes [F3] at index 8 from specified code page to Unicode.
El byte 0xf3 corresponde a la letra 'ó' en Latin-1/Windows-1252.

Causa
En el motor IronPython 2.7 (GhPython) de Rhino/Grasshopper, las funciones nativas open() o codecs.open() intentan decodificar los bytes usando la página de códigos ANSI por defecto del sistema Windows, lo que falla al encontrar caracteres fuera de esa codepage.

Solución
Se reemplazó el método estándar de lectura de JSON por una función robusta que usa la librería nativa de .NET (System.IO), la cual maneja rutas Unicode y codificación UTF-8 sin restricciones de códec.

Código implementado en F1_ETAPA1_CONTEXTO_v02.py:
import System.IO
import System.Text

def leer_json_seguro(ruta):
    """Lee archivos JSON soportando rutas y contenidos con tildes y eñes en IronPython."""
    if not ruta or not System.IO.File.Exists(str(ruta)):
        raise Exception("El archivo no existe en la ruta especificada: {}".format(ruta))
    
    # 1. Intento con UTF-8
    try:
        contenido = System.IO.File.ReadAllText(str(ruta), System.Text.Encoding.UTF8)
        return json.loads(contenido)
    except Exception as e_utf8:
        # 2. Fallback a codificación por defecto de Windows (CP1252 / Latin-1)
        try:
            contenido = System.IO.File.ReadAllText(str(ruta), System.Text.Encoding.Default)
            return json.loads(contenido)
        except Exception as e_default:
            raise Exception("Error al decodificar el archivo: {} | {}".format(e_utf8, e_default))

# Uso principal en el script:
try:
    data = leer_json_seguro(json_path)
    # ... continúa el procesamiento normal de lot_curve, vias, vecinos, etc.
except Exception as err:
    mensaje = "ETAPA1 | ERROR al leer JSON: {}".format(err)
