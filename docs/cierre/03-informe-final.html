06Lecciones aprendidas

  • La geobase POT es imperfecta; la clasificación automática es sugerencia, no verdad — el override del operador es la solución.
  • La lógica de mapeo vive en 3 lugares (Python + IronPython + JS): exige tests unitarios para no divergir.
  • IronPython 2.7 (GHPython) no admite f-strings, pathlib, type hints ni walrus.
  • Los derivados (data/pot-cache/*, resultados/*, .3dm) se regeneran y no son fuente de verdad.
